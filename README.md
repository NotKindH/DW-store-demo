# DW STORE — Phase 1 Demo

A responsive, dragon-themed storefront prototype built with plain HTML, CSS, and JavaScript.

## Included
- Responsive layout for phone, tablet, and desktop
- Sample product catalog
- Search, category filters, and sorting
- Interactive demo cart and quantity controls
- Demo-only checkout message
- No backend, no customer data collection, no live orders, and no payment processing

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Test the catalog and demo cart.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, e.g. `dw-store-demo`.
2. Upload `index.html` to the repository's root (the top level).
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear on the Pages settings screen.

Alternative: Cloudflare Pages can also host a static site. Create a Pages project, connect the GitHub repository, and use no build command with the output directory set to the repository root. Follow the current dashboard prompts.

## Important
This is a demo storefront. Sample prices are illustrative and do not represent real offers. It does not sell Blox Fruits or Roblox virtual items, create orders, or collect payments. Before enabling any real sales, confirm the relevant game-platform rules and payment-provider requirements. A production checkout would need a secure backend, private admin access, server-side validation, secure payment verification, and appropriate privacy/consumer policies. Do not place secret keys in browser code.
